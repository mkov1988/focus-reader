# Native parity 13: press feedback animation and header/search polish

**Done.** Implemented and committed as `07605cf` on `feat/native-ui-web-parity`, 2026-07-13, independent review passed with no unresolved findings. This package gave the native Android app the web app's press micromotion and top bar polish across the storefront, the inner page headers, and the search pills.

## What this fixed

Before this, native press states snapped instantly where the web tweens them, so pressing a row, chip, or button jumped rather than easing. The vibe hero's Start reading button carried a pressed dim the web does not have, the resume hero's progress bar jumped to its new width instead of animating, and the search pills were missing the web's inset shadow, focus ring, 16px text, and correct height. This package brought all eleven of those deltas to parity: every storefront press state now eases in and out over 150ms with the web's curve, the extra pressed dim is gone, the progress bar animates its width over 300ms, and the search pills gained the inset shadow, coral focus ring, 16px text, and correct heights.

Most of the deltas were one bug repeated: native `Pressable` style functions swapped pressed values instantly while the web tweens them over 150ms. A single shared hook, `usePressScale` (new `src/components/usePressScale.ts`), was built to drive those values through `withTiming` at 150ms with `Easing.bezier(0.4, 0, 0.2, 1)`, Tailwind's default transition curve, and reused at every call site. Files changed: `src/components/usePressScale.ts`, `src/components/ui.tsx`, `src/components/InnerPageHeader.tsx`, `src/components/SaveButton.tsx`, `src/components/rows.tsx`, `src/screens/TodayScreen.tsx`, `src/screens/VibeScreen.tsx`, `src/screens/ResultsScreen.tsx`.

## What changed

**1. Today press states and the vibe row inset shadow.** The web vibe row carries `transition-[transform,box-shadow,border-color] duration-150` on the default `cubic-bezier(0.4,0,0.2,1)` curve: while pressed the ring becomes `coral-accent/40`, scale drops to `0.99`, and an inset shadow `inset 0 1px 4px rgba(58,42,30,0.08)` fades in, with the icon chip tweening to scale `1.10` and rotate `-6deg` and the chevron sliding `translateX` 4px and its color to coral, all over 150ms; the Today menu button uses `active:scale-90` over 150ms. Native applied the same pressed values but as instant style swaps with no inset shadow. Fixed: the new `usePressScale` hook now drives the vibe row scale to 0.99, the ring color to coral, the icon tilt, the chevron slide plus a color cross fade, and a fading top inset shadow at `rgba(58,42,30,0.08)`, all over 150ms both ways, and the Today menu button tweens its shrink to 0.9.

**2. Library rows and the plain save button.** On the web, RecentRow and BookRow use `active:scale-[0.99]` with `transition-[transform,border-color] duration-150`, so the 0.99 press scale eases both ways while the ring color change to `coral-accent/40` stays instant (the ring is a box shadow, not in the transition list). The plain SaveButton uses `active:scale-90` with `transition-[transform,background-color,color] duration-150`, so its shrink to 0.9 and its background and icon color flip (cream/mocha when unsaved, coral accent with accent text when saved) all ease over 150ms. Native swapped all of these instantly. Fixed: RecentRow and BookRow now ease their 0.99 scale over 150ms while the border color swap stays instant, matching the web. The plain save button eases its 0.9 shrink and its saved color flip (background plus icon, via a cross fade of two bookmark icons) over 150ms, and its ring swap stays instant like the web.

**3. Filter chips and the ribbon shadow easing.** The web FilterChip uses `active:scale-[0.97]` with a 150ms transition on transform, background color, text color, and border color, and the ribbon bookmark's drape shadow fades with `opacity .4s ease`, where `ease` is `cubic-bezier(0.25, 0.1, 0.25, 1)`. Native snapped the chip and used reanimated's default in/out easing on the ribbon shadow's 400ms `withTiming`. Fixed: FilterChip now eases its 0.97 press scale and its active color flips (background, border, label) over 150ms with the shared curve, and the ribbon drape shadow's 400ms fade now uses the CSS ease curve, `bezier 0.25, 0.1, 0.25, 1`.

**4. Inner page header round buttons.** The web back and menu circles both carry `active:scale-90 transition-[transform,color] duration-150`, so the scale to 0.90 and back tweens over 150ms. Native toggled `transform: [{ scale: pressed ? 0.9 : 1 }]` instantly in both directions. Fixed: both circles now tween to 0.9 and back over 150ms via the shared hook. The web's `hover:text-coral-accent` has no native analogue and was not ported.

**5. Reader header collapse easing.** The web collapse animates `grid-template-rows` 1fr to 0fr plus opacity with `transition-[grid-template-rows,opacity] duration-300 ease-out`. Under Tailwind 3.4.17 the `ease-out` utility compiles to `cubic-bezier(0, 0, 0.2, 1)`, a strong decelerate that starts fast and lands gently, not the CSS `ease-out` keyword's `cubic-bezier(0, 0, 0.58, 1)`. Native ran `withTiming` at 300ms with no easing, so reanimated's default `Easing.inOut(Easing.quad)` applied and started slow. Fixed: the collapse now uses `bezier 0, 0, 0.2, 1` at 300ms. The line had drifted (an earlier round had added an `Easing.out` quad), so it was replaced with the exact Tailwind ease out curve. Only `InnerPageHeader.tsx` was touched, nothing under `src/reader/`.

**6. Today Popular "see all" icon and feedback.** On the web this is 13px semibold coral accent with an **ArrowRight** icon (size 14, `ml-1` so 4px left margin); while active the text dims to `coral-accent/70` (this button has `transition-colors`, so the dim tweens) and the arrow translates 4px right over 150ms. Native rendered **ChevronRight** at size 14 with a flat `opacity: 0.7` on the whole row and no icon slide. Fixed: ChevronRight was replaced with ArrowRight size 14, and while held the label and arrow now fade toward 70 percent and the arrow slides 4px right, both over 150ms with the shared curve, easing back on release. The copy ("see all", lowercase), size 13, semibold weight, and accent color already matched and were left alone.

**7. Native applied `opacity: 0.7` to the whole control and never moved the arrow. Fixed: the arrow now slides 4px right over 150ms with `Easing.bezier(0.4, 0, 0.2, 1)` while pressed and returns on release, and the 0.7 dim stays instant, matching the web's untransitioned color drop. This is the shared Swimlane component, so the fix lands everywhere it is used.

**9. **10. **11. Both search pills, inset shadow and exact height.** Both web pills (home and results) are cream with a 1px `espresso/10` ring, the inset shadow `inset 0 1px 3px rgba(58,42,30,0.08)`, and a `coral-accent/40` focus ring; input text is 16px Inter `font-medium`, espresso, placeholder `mocha/60`; icons are Search 18 at `mocha/70` and clear X 16 at `mocha/60`. The home pill's padding is 20 by 14 (`px-5 py-3.5`); the results pill's is 20 by 12 (`px-5 py-3`), which with the inherited 1.5 line height on 16px text makes it exactly 12 + 24 + 12 = 48px tall. Native rendered the results pill flat at about 40px with a 15px input. Fixed: the results pill got the same inset shadow, focus border swap to `t.accentA(0.4)`, and 16px text, plus 12px vertical container padding (input padding dropped to 0, minHeight 48) so it lands at about 48px. The Today pill's height was left alone as instructed. The shared treatment lives in one `TopInsetShadow` component in `ui.tsx`.

## Judgment calls

1. The inset shadow ink is hardcoded to `rgba(58,42,30,0.08)` instead of the theme ink helper. The web hardcodes that exact color, so in dark mode the shading stays dark; the theme ink would have flipped it into a light highlight, which would look wrong for a shadow.
2. The icon color tweens (vibe row chevron, plain save bookmark) use the suggested two stacked icons cross fading from one shared value, rather than animated SVG props.
3. The rows keep their instant border swap through a tiny pressed state flag set inside `onPressIn` and `onPressOut`, since a plain style function cannot ride on an animated pressable cleanly.
4. The Popular "see all" dim is an opacity fade to 0.7 on the label and arrow, which reads the same as the web's color drop to accent at 70 percent over its color transition.
5. The results pill lands at about 48px by pairing the 12px container padding with zero input padding and a 48 minimum height, since stacking 12px on top of the old 10px input padding would have made it about 64px tall.
6. The header collapse line had drifted from the prompt's snapshot (it already carried a quad ease out), so the described target was trusted and set to the exact `bezier 0, 0, 0.2, 1`.
7. No `app.json` version bump this round: another session held changes there, so the commit step handled the `expo.version` bump instead.
8. The package 03 cover inks decision did not intersect this package, so nothing was needed for it.
